# Changelog

## 1.3.0

### English

- Support Markdown images referenced by local paths and HTTP(S) URLs in Notebook cells, alongside embedded attachments.
- Apply hover presets, custom dimensions, settings, and edit-mode controls without rewriting references or converting files into attachments.
- Calculate percentages from loaded intrinsic dimensions and available cell width; handle delayed loads and resizing.
- Save local/hosted image sizes separately from attachment settings; preserve Notebook undo/redo and existing attachment metadata.

### 简体中文

- 支持 Notebook Markdown 单元格中的本地路径和 HTTP(S) 图床图片，兼容既有附件。
- 本地和图床图片共用悬浮档位、自定义尺寸、设置与编辑模式按钮，不改写引用、不转成附件。
- 根据加载后的原图尺寸和单元格宽度计算比例，支持延迟加载和窗口变化。
- 本地和图床图片尺寸独立保存，保留撤销、重做及原有附件元数据。
