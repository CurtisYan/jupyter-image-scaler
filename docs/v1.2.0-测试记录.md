# v1.2.0 测试记录

日期：2026-11-16。环境：macOS、VS Code 1.145.2。

## 改动

- 齿轮菜单新增「调整档位顺序」：支持上移、下移、移到最前和移到最后。每步立即保存，预览菜单、比例选择器及编辑模式按钮共用同一顺序。
- 新增「切换菜单样式」：保留左上角悬浮，增加「图片外部（自动避让）」。自动检查两侧空位，两侧放不下时在图片下方预留菜单空间。保持原有图片宽度，不遮挡图片或后续内容。
- 缩小字体、按钮内边距、按钮间距及菜单边框圆角。单行菜单高度由约 38px 降到 30px，齿轮改为独立的 18px SVG 图标。
- 样式保存在用户设置 `jupyterImageScaler.toolbarStyle`，排序保存在原有 `jupyterImageScaler.presets`。

## 验证

- 8 项单元测试通过。
- 实际安装的 VSIX：9 项扩展宿主检查通过，覆盖原有缩放命令、附件字节不变、保存、重新打开、撤销与重做。
- 实际安装的 VSIX：16 项真实界面检查通过。在原有自定义比例、尺寸、附件定位等检查之外，覆盖全部四种排序操作、即时同步、紧凑菜单与齿轮尺寸、图片外部菜单与下方回退、窗口变窄、靠右图片的左侧空位，以及切换回悬浮样式。
- 窗口尺寸变化测试未出现 ResizeObserver 错误。100% 图片宽度不因菜单样式改变；原有大图四档仍实测为 198.5、397、595.5、794px。

原始结果：`test/results/v1.2.0-host.json`、`test/results/v1.2.0-installed-hover.json`。截图：`docs/images/外部菜单.png`。
