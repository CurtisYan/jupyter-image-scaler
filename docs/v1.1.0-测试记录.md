## 使用边界

只处理 Markdown `attachment:` 图片。同一单元格内同名附件的多个引用共用尺寸；不同单元格独立。优先使用 Notebook 单元格 ID 定位，旧文件没有 ID 时仅在源码唯一匹配时操作，遇到歧义提示使用单元格菜单，避免改错图片。

百分比使用默认显示宽度；只填像素宽度保持比例；指定宽高可能改变原图比例。像素宽度不会超出单元格可用宽度。安装更新后，原有 VS Code 窗口需要执行「开发人员：重新加载窗口」。本次不创建 GitHub Release 或版本标签。
