## English

- Added scaling for **local and hosted Markdown images**, alongside embedded attachments.
- Reuse hover presets, custom dimensions, and toolbar settings without changing image references or files.
- Sizes persist with the Notebook; undo/redo supported.

**Install/update:** download the VSIX below → **Install from VSIX…** → save your work and run **Developer: Reload Window**. Requires VS Code 1.100+. UI currently in Chinese.

## 简体中文

- 新增 **本地路径和图床图片** 缩放，兼容内嵌附件。
- 共用悬浮档位、自定义尺寸及菜单设置，不改写图片引用或文件。
- 尺寸随 Notebook 保存，支持撤销、重做。

**安装/更新：** 下载下方 VSIX → **从 VSIX 安装…** → 保存文件并执行 **开发人员：重新加载窗口**。要求 VS Code 1.100+，目前界面为中文。
